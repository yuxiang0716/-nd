# NDHU Sports Fields

## Prerequest
You need to have:

- [Java](https://www.oracle.com/java/) installed
- [Google Chome](https://www.google.com/chrome/) installed


## How to Run
### Windows 
Double click on `run.bat`

### Linux or MacOs
At project root directory

`./gradlew run`


## Procedure to Operate this Application
1. At `app/src/main/java/sportsfieldspicker/SportsFieldsPicker.java` Fill the line 32 to 40 according to your requirment
2. At maximum 20 minutes earlier, follow the instruction at `app/src/main/java/sportsfieldspicker/Capcha.java`
3. Then you can run the application based on How to Run above
